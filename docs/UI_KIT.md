# UI Kit — HR-портал

Источник: исходный кит компании (`ui_kit.txt` в проекте), адаптированный под задачи портала. Где кита не хватало — решения принимались самостоятельно, с той же характерностью (пилюли, Montserrat). Документ живой — дополняется по ходу разработки.

## Цвета

| Токен | Hex | Назначение |
|---|---|---|
| `--color-text-primary` | `#000209` | Заголовки, основной текст, фон primary-кнопки |
| `--color-text-secondary` | `#37393F` | Обычный текст, описания |
| `--color-text-tertiary` | `#63656E` | Второстепенный текст, подписи |
| `--color-text-muted` | `#999A9D` | Плейсхолдеры, disabled, рамки инпутов |
| `--color-bg-page` | `#F7F9FC` | Фон страницы |
| `--color-bg-card` | `#EDEEF2` | Фон карточек, hover у secondary-кнопки *(адаптация: в ките это просто светлый нейтральный цвет, роль "карточка" придумана нами)* |
| `--color-bg-alt` | `#F9FAFD` | Альтернативный светлый фон |
| `--color-white` | `#FFFFFF` | Фон белых кнопок/полей |
| `--color-danger` | `#FF3860` | Ошибки, удаление, критичные пометки |
| `--color-success` | `#18CB00` | Успех, "готово", подтверждения |
| `--color-primary-hover` | `#26282E` | *(придумано нами)* — hover для чёрной кнопки, кита не было точного значения |

## Кнопки

Форма — пилюля, `border-radius: 40px`, высота ~46–48px, паддинг `0 40px`.

- **Primary (чёрная)** — фон `--color-text-primary`, текст белый. Hover — `--color-primary-hover`. Disabled — фон `--color-text-muted`.
- **Secondary (белая)** — фон белый, текст `--color-text-primary`, рамка `--color-text-muted`. Hover — фон `--color-bg-card`.

*(Ховер/disabled-эффекты — наша интерпретация: в ките были только Figma-координаты позиций состояний, не конкретные визуальные дельты)*

## Поля ввода

Пилюля, `border-radius: 40px`, высота 48px, паддинг `0 20px`, рамка 1px `--color-text-muted`, фокус — рамка `--color-text-primary`.

*(Textarea — исключение из "пилюли": радиус 16px, многострочный текст в форме пилюли нечитаем)*

## Карточки *(в ките не было)*

Фон `--color-bg-card`, радиус 10px, паддинг 24px.
